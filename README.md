# Fast Floor / 极速刷楼 · 出字即停

SillyTavern 扩展，收到第一段流式文字（思考或正文）就中断当前生成，保留这一层，保存完成后立即生成下一层，直到达到目标层数。

## 安装与更新

在酒馆的扩展管理中安装本仓库：

https://github.com/zhanghaoyu2365-ship-it/SillyTavern-FastFloor

已安装旧版：更新扩展后刷新酒馆页面。版本为 **1.1.1**，设置标题为 **⚡ 极速刷楼 · 出字即停**。

手动安装时将整个文件夹放入当前用户扩展目录，例如 `data/default-user/extensions/SillyTavern-FastFloor`。需包含 `manifest.json`、`index.js`、`runner.js`、`style.css`。

## 使用

1. 在酒馆 API 设置里开启**流式传输**，并连接支持流式输出的接口。
2. 打开角色聊天或群聊，先发送或保存输入框里的草稿。
3. 打开扩展设置中的 **⚡ 极速刷楼 · 出字即停**。
4. 设置层数，隐藏提示词默认是“继续”，先用 3 层确认接口表现。
5. 点击“开始”：等待出字 → 打断 → 保存本层 → 下一层。
6. 点击插件“立即停止”或酒馆原有停止按钮，会终止整批刷楼。

隐藏提示词不会成为用户消息。群聊每层只调用一位角色，优先沿用上一位启用的发言者，否则使用第一位启用的成员。运行期间暂时禁用聊天输入框，结束后恢复，以免自动生成清空新输入的草稿。

## 行为与限制

- “出字即停”指第一段有效流式文字（思考或正文）到达后立即发送中断指令，不保证精确到一个字。接口一次可能返回几个字或一小段。
- 不设置额外刷楼间隔，但必须等当前生成结束并保存，才发起下一次请求，不并发叠加。
- 独立思考字段和内嵌思考文字均可触发中断。只有思考内容、正文为空的楼层也会保留并计数；空白、思考计时和没有文字的标记不会单独计数。
- 不能跳过模型的首字等待时间；停止也不保证服务商立即停止后台计算或计费。
- 切换聊天会停止本批后续生成；API 报错、没有检测到流式文字或没有有效保存的 AI 回复时停止，不自动无限重试。
- 接口、正则脚本、模型工具调用或其他自动生成扩展可能影响最终保存的内容。建议先用普通文本模型、3 层测试。
- 不刷新网页，也不覆盖上一层；每次都新增一个 AI 楼层。
